Icon Set — Google Material Symbols

The whole Material Symbols Outlined family (~2,500 icons) is loaded via Google Fonts below, so any icon name works immediately — not just the ones shown here. This page curates the ones actually used across our prototypes so far, for quick copy-paste, plus the pattern for pulling any other icon from the full set.

How to use any icon, including ones not shown below:
1. Find its name at fonts.google.com/icons (use the "Outlined" style to match this design system).
2. Add this markup: <span class="material-symbols-outlined">icon_name</span>
3. Make sure the page <head> includes the font link from the top of this file's source.
Size via font-size, color via color — same as any inline text.
